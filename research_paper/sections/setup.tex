\section{Experimental Setup}
\label{sec:setup}

\Cref{tab:grid} lists the experiments; each row is one configuration file in the released
repository. All use five seeds. On the generated corpus each seed is its own corpus; on Enron the
seeds re-draw events from one corpus. Real-model cells have 200 revocation events (5 seeds $\times$
40), sized so that a difference of \pending{0.05} in $\LM$ is detectable at 80\% power under the
variance of the pilot runs (\cref{app:pilot}).

\paragraph{Probe schedule.}
0\,s, 10\,min, 1\,h, 4\,h, 12\,h, 24\,h and 48\,h after revocation; the lifetime experiment adds
1\,min, 30\,min, 2\,h, 8\,h, 18\,h and 36\,h.

\paragraph{Environment.}
\pending{GPU type, vLLM version, model revisions}; Python 3.14, scikit-learn 1.9.1, ChromaDB 1.5.9,
sentence-transformers 6.1.0. Latency results are comparable within the paper only. Runs of different
(configuration, seed) pairs execute in parallel against one vLLM server per GPU; each pair has its own
seeded random streams and output, and a test checks that parallel and sequential runs produce
identical rows. Existence runs, which measure latency, send one request at a time to each server,
so every call is timed on an otherwise idle GPU.
