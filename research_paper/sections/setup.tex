\section{Experimental Setup}
\label{sec:setup}

\Cref{tab:grid} lists the experiments; each row is one configuration file in \texttt{configs/min/} of
the released repository. All use the Enron corpus with canaries and five seeds, which re-draw
revocation events from the one corpus. The model run has 100 revocation events per cell (5 seeds
$\times$ 20); the stub runs have 200.

\paragraph{Probe schedule.}
The model run probes 0\,s, 1\,h and 24\,h after revocation; the stub runs probe at 0\,s, 10\,min,
1\,h, 4\,h, 12\,h, 24\,h and 48\,h.

\paragraph{Environment.}
One laptop with an RTX 3050 laptop GPU (6\,GB) running Ollama \pending{version} with the default
4-bit build of Llama-3.1-8B; Python 3.14, scikit-learn 1.9.1, ChromaDB 1.5.9, sentence-transformers
6.1.0. Runs are sequential. Latency results are comparable within the paper only.
