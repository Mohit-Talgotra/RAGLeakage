\subsection{RQ4: What closes each channel?}
\label{sec:rq4}

\paragraph{Ablation.}
\pending{R4a: leave-one-out from full; LM without transitive taint, and with the one-hop variant
(summaries carry their turns' documents, answers do not inherit memory taint), which separates the
summary half of transitivity from the answer half.} An identifier-based purge (\texttt{legacy})
cannot reach a summary, but the pilot comparison of \texttt{legacy} with \texttt{baseline} cannot show
it: both keep the stale index, which dominates total leakage, and \texttt{legacy} does reduce memory
leakage (0.322 to 0.230 in the pilot). The ablation with the live ACL check in place is the clean
test.

\paragraph{Inference side.}
\pending{R4b: with the pre-filter off and scores computed only over authorized chunks, the residual
post-filter channels (fewer sources returned, rank displacement, latency); the same cell with
withheld scores exposed, as a named misconfiguration; fast-refusal effect without padding.}

\pending{R4s (p4\_shared\_state): LM\_new through a colleague's cache entries, baseline\_shared vs

\pending{R4c: the published retrieval-time designs remove index leakage and leave cache and memory

result whichever way it goes: if epoch invalidation keeps as much retained recall as taint, the
simpler mechanism is the recommendation.}
