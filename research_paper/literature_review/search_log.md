# Search log — Phase 0 literature audit

Search dates: 2026-10-14. Platforms: OpenAlex REST API, Crossref REST API,
publisher landing pages (ACM DL, IEEE Xplore, Springer Link, PMLR, USENIX,
Nature/Sci Rep, SciTePress), conference program pages (ICML 2026, NeurIPS 2026,
SaTML 2026), Elsevier Pure institutional records, general web search.

This is **not** a PRISMA systematic review. It is a targeted, traceable audit of
one manuscript's bibliography plus a thematic sweep for missed prior art. No
claim of exhaustive field coverage is made.

## Queries run

### A. Verification of existing bibliography (51 entries, two groups)

`references.bib` line 190 carries the marker `% ---- Added for the expanded
related work ----`, splitting the file into the author's **vetted baseline of
21** entries (lines 1-189) and a later **expansion of 30** entries (lines
190-442). The expansion is not author-vetted, so under Phase 0 section 3
("references generated by a language model without independent verification")
those 30 carried the burden of proof and were the priority for checking.

Method: DOI path lookup on `api.openalex.org/works/doi:<DOI>` for every entry
carrying a DOI; for DOI-less proceedings entries, the publisher's own
proceedings page (USENIX, PMLR, ACL Anthology, NeurIPS proceedings, conference
virtual site). Entries checked individually.

Outcome: **50 of 51 confirmed against a registry or publisher record; 1 partial
(`wu2025know`, venue confirmed, DOI lookup rate-limited); 1 with unresolved
fields (`song2025earlybird`); 0 fabricated.** All 30 expansion entries resolve
to real publications. Per-entry trail in `verification_report.md`; the
`bib_group` column of `literature_matrix.csv` records each entry's group.
