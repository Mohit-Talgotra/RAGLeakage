\paragraph{Probe schedules.}
The default schedule is 0\,s, 1\,min, 10\,min, 30\,min, and 1, 2, 4, 8, 12, 24, 36 and 48\,h. The sync-policy experiment (2a) uses 0\,s, 1, 5, 15 and 30\,min, and 1, 2, 4, 6, 12, 18, 24, 36 and 48\,h.

\paragraph{Sync policies.}
\emph{Periodic} crawls refresh the index ACL copy every $\Delta$ seconds. \emph{Event-driven} sync updates it when a webhook fires; a drop probability models lost webhooks, with an optional daily crawl as backstop.

\paragraph{Implementation notes that affect interpretation.}
Three corrections were made before the final runs. (i)~The cache-threshold sweep first repeated the exact warm-up question (cosine similarity 1.0), so every threshold behaved identically; the final run rewords the probe with one of seven templates (cosine 0.79--0.98 to the original). (ii)~The blast-radius metric was added because target-only $\LM$ cannot distinguish revocation types by construction. (iii)~The attacker's latency is rounded to 1\,ms: sub-millisecond floating-point noise from the simulator had produced a spurious AUC of 0.58 in the padded condition, and after rounding every padded-deadline cell is exactly 0.500. The rounding stands in for network jitter and is not a calibrated noise model.

\paragraph{Environment.}
Runs used Python 3.14, scikit-learn 1.9.1, ChromaDB 1.5.9 and sentence-transformers 6.1.0 on an Apple M5 laptop with 16\,GB of memory, with Ollama serving \texttt{qwen2.5:3b} for the real-model check.
