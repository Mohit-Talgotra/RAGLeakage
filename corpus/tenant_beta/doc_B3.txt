VOLTAIC SYSTEMS — OPEN POSITIONS (ENGINEERING)
Effective: January 2026 | All roles are hybrid (Austin, TX preferred; remote considered)

SENIOR SOFTWARE ENGINEER — REAL-TIME SYSTEMS
────────────────────────────────────────────────────────────────
Team: Grid Edge Platform
Responsibilities:

familiarity with IEC 61850 or DNP3 a plus. Compensation: $175K–$210K base + equity.

Requirements: 3+ yr ML engineering, TensorFlow/PyTorch, model quantisation experience.
Compensation: $160K–$195K base + equity.

SITE RELIABILITY ENGINEER — CLOUD & EDGE

Team: Infrastructure

Requirements: 4+ yr SRE/DevOps, Kubernetes, Terraform, Prometheus/Grafana.
Compensation: $155K–$185K base + equity.
